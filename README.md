# Office RAG Assistant

A retrieval-augmented generation assistant for querying internal documents.

## What it does
- Hybrid retrieval (TF-IDF + embeddings)
- LangChain pipeline for structured answers over document collections
- Simple interface for question answering

## Stack
Python, LangChain, HuggingFace / embeddings, FastAPI or Gradio (whichever you used)

## Status
Research / prototype project demonstrating end-to-end RAG design.
